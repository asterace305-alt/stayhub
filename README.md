#  StayHub
### AI-Powered PG Finder for VIT Pune

StayHub helps VIT Pune students find verified PG accommodation near campus using a personalised AI Fit Score — no brokers, no scams, no hidden costs.

---

## What it does
- **Fit Score** — ranks every PG out of 100 based on YOUR preferences
-  **Verified Listings** — 3-tier owner KYC system
-  **AI Chatbot** — answers VIT Pune specific accommodation queries
-  **Legal Help** — Leave & License templates + Pune Police verification guide
-  **Surge Detection** — flags admission season price hikes

---

## Tech Stack
- **Frontend** — React.js
- **Backend** — Node.js + Express + MongoDB
- **AI** — Python + Claude AI API
- **Maps** — Google Maps API
- **Auth** — Firebase
